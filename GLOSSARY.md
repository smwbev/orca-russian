# Глоссарий локализации Orca (ru-RU)

Рабочий документ для перевода `src/renderer/src/i18n/locales/en.json` (11 377 строк).
**В git не добавляется** — репозиторий содержит только `orca-plugin.json` и `locales/ru-RU.json`.

## Общие правила

1. **Безличные формы.** «Выберите язык», «Не удалось подключиться», а не «Вы можете…» / «Ты можешь…».
2. **Плейсхолдеры переносятся дословно:** `{{value0}}`, `{{path}}`, `{{hostName}}` — не переводить, не менять регистр, не переставлять без необходимости. Затрагивает 980 строк.
3. **Гибридная терминология:** элементы интерфейса переводим, git/CLI-команды и имена продуктов оставляем латиницей.
4. **Буква «ё» пишется последовательно:** «ещё», «её», «упрощённый», «удалённый».
5. **Многоточие — символом `…`**, не тремя точками. Кавычки — «ёлочки», внутри них — „лапки“.
   Исключение: внутри примеров кода, команд, URL и путей многоточие остаётся ASCII —
   `orca://pair?code=...`, иначе строка перестаёт читаться как образец для копирования.
6. **Тире — длинное «—»** с пробелами; дефис в составных терминах — короткий: «SSH-хост», «QR-код».
7. **Строки, начинающиеся с заглавной (кнопки, пункты меню), сохраняют заглавную.** Заголовки Title Case из английского переводим обычным предложением: «Open Worktree Palette» → «Открыть палитру рабочих деревьев».
8. **Не переводим:** CSS-строки (247 шт.), содержимое `auto.components.settings.plugin*` (214 шт., движок отклонит весь пакет).

## Известные ограничения

- **Множественное число.** Пакет подключается под синтетическим кодом языка `plugin<hex>`, а не `ru`, поэтому правила плюрализации русского языка могут не примениться. Затрагивает 10 ключей (`_one` / `_other`). До проверки на живом приложении для них используем формулировки без склонения числа: «Файлов: {{count}}» вместо «{{count}} файла».
- **Защищённая зона.** 214 строк `auto.components.settings.plugin*` остаются на английском — переопределение запрещено движком.
